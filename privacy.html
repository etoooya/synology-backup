Privacy Policy

Effective date: November 26, 2026

Purpose

Synology Backup is a personal backup application that copies Google Drive files to a privately managed Synology NAS using rclone.

Data Access

The application requests read-only access to Google Drive files and metadata solely for backup purposes.

Data Storage and Security

Backup files and authorization credentials are stored on the owner's privately managed NAS. Access is restricted to authorized users.

Data Sharing

The application does not sell, share, or transfer Google user data to third parties for advertising, analytics, or other unrelated purposes.

Data Retention and Deletion

Backup retention is controlled by the owner. Stored backups can be deleted directly from the NAS. Google Drive authorization can be revoked through Google Account security settings.

Google API Services

The application's use of Google user data adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions may be submitted through the project's GitHub repository.
